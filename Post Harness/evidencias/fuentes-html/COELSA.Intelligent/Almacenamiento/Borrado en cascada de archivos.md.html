0010 # Borrado en cascada de archivos
0011
0012 ## Qué es
0013
0014 Cuando un usuario **elimina una conversación (chat)**, COELSA.Intelligent elimina automáticamente todos los archivos asociados a esa conversación, tanto en la base de datos como en [[MinIO S3]].
0015
0016 ## Por qué existe
0017
0018 Sin esta funcionalidad, eliminar un chat dejaría archivos huérfanos en MinIO indefinidamente. A largo plazo, esto genera acumulación de storage sin posibilidad de recuperarlo sin una migración manual.
0019
0020 ## Implementación
0021
0022 El modelo `File` tiene una columna `chat_id` (con índice):
0023
0024 ```python
0025 class File(Base):
0026 chat_id = Column(String, nullable=True, index=True)
0027 # Vinculación con chats para borrado en cascada
0028 ```
0029
0030 Cuando el endpoint de eliminación de chat se ejecuta:
0031 1. Busca todos los registros `File` donde `chat_id == chat.id`
0032 2. Para cada archivo: llama a `StorageProvider.delete_file(file.path)`
0033 3. Elimina los registros de la tabla `file`
0034 4. Elimina el registro del chat
0035
0036 ## Diferencia con el Scheduler
0037
0038 | Mecanismo | Cuándo actúa | Qué elimina |
0039 |-----------|-------------|-------------|
0040 | **Borrado en cascada** | Al eliminar un chat | Archivos del chat eliminado |
0041 | **[[Scheduler de limpieza]]** | Diariamente | Huérfanos + archivos vencidos |
0042
0043 Ambos mecanismos son complementarios.
0044
