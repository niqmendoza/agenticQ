0010 # Azure AD login exclusivo
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent tiene **deshabilitados** el registro de nuevos usuarios vía formulario web y el login con email/contraseña. El **único** medio de autenticación es Azure Active Directory via OAuth 2.0.
0015
0016 ## Qué está deshabilitado
0017
0018 - Formulario de registro de usuario (el endpoint existe pero rechaza requests)
0019 - Login con email + contraseña
0020 - Auto-signup (creación automática de cuenta al primer login configurada en modo restringido)
0021
0022 ## Por qué esta decisión
0023
0024 COELSA es una empresa con Azure AD como directorio corporativo. Usar Azure AD:
0025 - Unifica la gestión de usuarios con el directorio existente
0026 - Elimina la necesidad de gestionar contraseñas en la aplicación
0027 - Permite aprovechar políticas de seguridad (MFA, Conditional Access) del tenant corporativo
0028 - Cumple con las políticas de seguridad de TI de COELSA
0029
0030 ## Variables requeridas
0031
0032 ```env
0033 OAUTH_CLIENT_ID=<azure-client-id>
0034 OAUTH_CLIENT_SECRET=<azure-client-secret>
0035 OAUTH_PROVIDER_NAME=microsoft
0036 OPENID_PROVIDER_URL=https://login.microsoftonline.com/<tenant-id>/v2.0/.well-known/openid-configuration
0037 ```
