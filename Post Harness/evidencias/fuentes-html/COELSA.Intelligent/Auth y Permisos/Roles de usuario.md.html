0009
0010 # Roles de usuario
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent define tres roles de usuario, almacenados en el campo `role` del modelo `User`:
0015
0016 | Rol | Descripción | Capacidades principales |
0017 |-----|-------------|------------------------|
0018 | `admin` | Administrador del sistema | Acceso total; gestión de usuarios, grupos, modelos, configuración |
0019 | `user` | Usuario activo | Chat, upload de archivos, uso de bases de conocimiento según permisos |
0020 | `pending` | En espera de aprobación | Solo puede ver la pantalla de espera; no puede usar el chat |
0021
0022 ## Estado `pending`
0023
0024 Un usuario recién logeado por primera vez via Azure AD puede quedar en estado `pending` si la configuración requiere aprobación manual. Un admin debe cambiar el rol a `user` para habilitar el acceso.
0025
0026 ## Restricciones por rol en la UI
0027
0028 En la vista de **Settings**, las siguientes tabs están restringidas a `admin`:
0029 - **Personalization** — configuración visual de la app
0030 - **Audio** — configuración de síntesis y transcripción de voz
0031
0032 Los usuarios `user` ven estas tabs pero no pueden acceder a su contenido.
0033
0034 ## Funcionalidades deshabilitadas para todos los roles
0035
0036 Independientemente del rol, estas funcionalidades están desactivadas en el fork:
0037 - Sugerencias de chat automáticas
0038 - Ejecución de Python en CodeBlocks
0039 - Webhooks en la sección Account
