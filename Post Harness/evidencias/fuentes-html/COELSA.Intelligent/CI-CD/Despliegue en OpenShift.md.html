0010 # Despliegue en OpenShift
0011
0012 ## Pasos de despliegue
0013
0014 ### Prerequisitos (primera vez)
0015
0016 1. **Crear el bucket MinIO**:
0017 ```bash
0018 python scripts/create_minio_bucket.py
0019 ```
0020 Requiere que las variables `S3_*` estén en `.env`.
0021
0022 2. **Aplicar ConfigMap** con variables de entorno:
0023 ```bash
0024 oc apply -f docs/OPENSHIFT-CONFIGMAP.yaml
0025 ```
0026
0027 3. **Aplicar configuración de Routes** (incluye CSP):
0028 ```bash
0029 oc apply -f docs/OPENSHIFT-ROUTE-CONFIG.yaml
0030 ```
0031
0032 ### Deploy de una nueva versión
0033
0034 Ejecutar el pipeline correspondiente:
0035 - **DEV**: `azure-pipeline-DEV.yml`
0036 - **VALIDACION**: `azure-pipeline-VALIDACION.yml`
0037 - **PRODUCCIÓN**: `azure-pipeline-PROD.yml`
0038
0039 ### Migraciones de base de datos
0040
0041 ```bash
0042 cd backend
0043 alembic upgrade head
0044 ```
0045
0046 El servidor aplica migraciones automáticamente al arrancar. Si hay migraciones pendientes críticas, ejecutarlas manualmente antes del deploy.
0047
0048 ## Configuración crítica del Route
0049
0050 ### Timeout de HAProxy
0051
0052 El timeout de HAProxy en el Route **debe ser mayor a 300 segundos**. El procesamiento de archivos con RAG (embedding + inserción en Milvus) puede superar 5 minutos en documentos grandes.
0053
0054 ```yaml
0055 # En la anotación del Route de OpenShift
0056 haproxy.router.openshift.io/timeout: 600s
0057 ```
0058
0059 ### CSP para SharePoint
0060
0061 Si [[SharePoint OneDrive integración]] está activo, incluir en la CSP:
0062 ```
0063 connect-src: login.microsoftonline.com graph.microsoft.com
0064 ```
