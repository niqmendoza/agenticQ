0010 # COELSA.Intelligent — Home
0011
0012 Plataforma interna de chat con IA generativa de COELSA. Fork de Open WebUI adaptado para infraestructura corporativa: autenticación Azure AD, almacenamiento MinIO/S3, búsqueda vectorial Milvus, identidad visual COELSA y despliegue en OpenShift.
0013
0014 **Versión actual:** v1.3.0
0015 **Entornos activos:** DEV · VALIDACION · PRODUCCIÓN (OpenShift)
0016 **Repo base:** Fork de Open WebUI (MIT); cambios aplicados sobre versión estabilizada sin seguimiento del upstream.

0024 ## Invariantes del proyecto (reglas que nunca se rompen)
0025
0026 - La autenticación es **exclusivamente Azure AD**; el registro local y el formulario de login están deshabilitados.
0027 - **Teal (`#06ABB9`) es el color primario COELSA** en ambos temas (light y dark). Pink es solo acento decorativo.
0028 - SSR está deshabilitado (`export const ssr = false`); la app es una SPA pura.
0029 - No se mantiene compatibilidad directa con el upstream Open WebUI; los cambios se aplican deliberadamente.
0030 - Todo par texto/fondo debe cumplir WCAG AA (4.5:1 texto normal, 3:1 texto grande).
0031 - No hardcodear valores hex en componentes; usar siempre roles/tokens semánticos del ECO Design System.
