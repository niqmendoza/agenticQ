0009
0010 # Agregar proveedor de almacenamiento
0011
0012 ## Qué es
0013
0014 Guía para implementar un nuevo backend de almacenamiento en COELSA.Intelligent. El sistema usa una interfaz abstracta `StorageProvider` que permite agregar nuevos providers sin modificar el código de negocio.
0015
0016 ## La interfaz abstracta
0017
0018 ```python
0019 # backend/server/storage/provider.py
0020 class StorageProvider(ABC):
0021
0022 @abstractmethod
0023 def get_file(self, file_path: str) -> str:
0024 """Retorna la ruta local o URL al archivo."""
0025 pass
0026
0027 @abstractmethod
0028 def upload_file(self, file: BinaryIO, filename: str) -> Tuple[bytes, str]:
0029 """Sube el archivo y retorna (contenido, path)."""
0030 pass
0031
0032 @abstractmethod
0033 def get_presigned_url(self, file_path: str, expiration: int = 3600) -> str:
0034 """Genera una URL firmada de acceso temporal."""
0035 pass
0036
0037 @abstractmethod
0038 def get_storage_stats(self) -> dict:
0039 """Retorna estadísticas de uso del almacenamiento."""
0040 pass
0041
0042 @abstractmethod
0043 def delete_all_files(self) -> None:
0044 pass
0045
0046 @abstractmethod
0047 def delete_file(self, file_path: str) -> None:
0048 pass
0049 ```
0050
0051 ## Pasos para agregar un nuevo provider
0052
0053 ### 1. Crear la clase del provider
0054
0055 ```python
0056 # backend/server/storage/provider.py — agregar junto a las clases existentes
0057 class MiNuevoProvider(StorageProvider):
0058
0059 def get_file(self, file_path: str) -> str:
0060 # implementación
0061 ...
0062
0063 def upload_file(self, file, filename):
0064 # implementación con sanitización de path (ver Path Traversal)
0065 ...
0066
0067 # ... implementar todos los métodos abstractos
0068 ```
0069
0070 ### 2. Registrar en la factory
0071
0072 En `provider.py`, agregar el nuevo provider a la selección por variable de entorno:
0073
0074 ```python
0075 STORAGE_PROVIDER = os.getenv("STORAGE_PROVIDER", "local")
0076
0077 if STORAGE_PROVIDER == "s3":
0078 Storage = S3StorageProvider(...)
0079 elif STORAGE_PROVIDER == "mi-nuevo":
0080 Storage = MiNuevoProvider(...)
0081 else:
0082 Storage = LocalStorageProvider()
0083 ```
0084
0085 ## Notas de seguridad
0086
0087 Siempre incluir sanitización de path traversal en `upload_file`. Ver [[Path Traversal]].
