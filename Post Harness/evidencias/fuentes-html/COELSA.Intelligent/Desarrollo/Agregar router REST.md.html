0010 # Agregar router REST
0011
0012 ## Qué es
0013
0014 Guía paso a paso para agregar un nuevo conjunto de endpoints REST al backend de COELSA.Intelligent usando el patrón de routers de FastAPI.
0015
0016 ## Pasos
0017
0018 ### 1. Crear el módulo del router
0019
0020 ```python
0021 # backend/server/routers/mi_nuevo_router.py
0022 from fastapi import APIRouter, Depends, HTTPException
0023 from server.models.users import UserModel
0024 from server.utils.auth import get_current_user
0025
0026 router = APIRouter()
0027
0028 @router.get("/")
0029 async def get_items(user: UserModel = Depends(get_current_user)):
0030 """Endpoint de ejemplo."""
0031 return {"items": []}
0032
0033 @router.post("/")
0034 async def create_item(
0035 data: dict,
0036 user: UserModel = Depends(get_current_user)
0037 ):
0038 return {"created": True}
0039 ```
0040
0041 ### 2. Importar el router en `main.py`
0042
0043 ```python
0044 # backend/server/main.py
0045 from server.routers import (
0046 # ... routers existentes ...
0047 mi_nuevo_router, # Agregar aquí
0048 )
0049 ```
0050
0051 ### 3. Registrar el router en la app
0052
0053 ```python
0054 # backend/server/main.py — en la función que monta los routers
0055 app.include_router(
0056 mi_nuevo_router.router,
0057 prefix="/api/v1/mi-recurso",
0058 tags=["mi-recurso"]
0059 )
0060 ```
0061
0062 ## Convenciones
0063
0064 - Los routers usan el prefijo `/api/v1/`
0065 - Todos los endpoints que requieren autenticación usan `Depends(get_current_user)`
0066 - Los errores usan la jerarquía del [[Sistema de errores centralizado]]
0067 - La lógica de acceso a BD va en `backend/server/models/`; el router solo orquesta
