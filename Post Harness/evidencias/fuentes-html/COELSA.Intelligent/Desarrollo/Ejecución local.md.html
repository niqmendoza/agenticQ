0010 # Ejecución local
0011
0012 ## Qué es
0013
0014 Guía de referencia para levantar COELSA.Intelligent en modo desarrollo local.
0015
0016 ## Prerrequisitos
0017
0018 Tener corriendo localmente (o con Docker):
0019 - [[PostgreSQL]] 14+ en `localhost:5432`
0020 - [[Redis]] 7+ en `localhost:6379`
0021 - [[Milvus]] 2.4+ en `localhost:19530`
0022 - [[MinIO S3]] en `localhost:9000` (opcional; puede usarse storage local)
0023 - [[Ollama]] o [[LiteLLM proxy]] para los modelos IA
0024
0025 ## Configuración inicial
0026
0027 ```bash
0028 # 1. Copiar y editar variables de entorno
0029 cp .env.example .env
0030
0031 # 2. Editar .env con las conexiones locales y credenciales de Azure AD
0032 ```
0033
0034 Variables mínimas requeridas: ver `docs/setup.md`.
0035
0036 ## Levantar el backend
0037
0038 ```bash
0039 cd backend
0040 pip install -r requirements.txt # Primera vez
0041
0042 # Linux / macOS
0043 ./dev.sh
0044
0045 # Windows
0046 start_windows.bat
0047 ```
0048
0049 El backend queda disponible en `http://localhost:8080` con **hot-reload** activado.
0050
0051 ## Levantar el frontend
0052
0053 ```bash
0054 # Primera vez
0055 npm install
0056
0057 npm run dev
0058 ```
0059
0060 El frontend queda disponible en `http://localhost:5173`. Apunta automáticamente al backend en `localhost:8080`.
0061
0062 ## Notas de desarrollo
0063
0064 - Los [[CSP con nonces|nonces CSP]] deben estar deshabilitados en local (`ENABLE_CSP_NONCES=false`)
0065 - Los logs del backend usan loguru — ver [[Loguru y logging]]
0066 - Para probar el storage S3, configurar `STORAGE_PROVIDER=s3` con las vars de [[MinIO S3]]
0067 - Las migraciones se aplican automáticamente al arrancar el backend — ver [[Migraciones Alembic]]
0068
