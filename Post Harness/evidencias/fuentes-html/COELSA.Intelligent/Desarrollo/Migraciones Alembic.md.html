0009
0010 # Migraciones Alembic
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent usa **Alembic** para gestionar los cambios de esquema de [[PostgreSQL]]. Las migraciones están en `backend/server/migrations/`.
0015
0016 ## Arranque automático
0017
0018 Al iniciar el servidor, `run_migrations()` en `config.py` aplica automáticamente las migraciones pendientes:
0019
0020 ```python
0021 # backend/server/config.py
0022 def run_migrations():
0023 from alembic import command
0024 from alembic.config import Config
0025 alembic_cfg = Config(SERVER_DIR / "alembic.ini")
0026 command.upgrade(alembic_cfg, "head")
0027 ```
0028
0029 ## Comandos manuales
0030
0031 ```bash
0032 # Aplicar todas las migraciones pendientes
0033 cd backend
0034 alembic upgrade head
0035
0036 # Ver el estado actual
0037 alembic current
0038
0039 # Ver el historial de migraciones
0040 alembic history
0041
0042 # Crear una nueva migración (autogenerada)
0043 alembic revision --autogenerate -m "descripcion_del_cambio"
0044
0045 # Crear una migración manual vacía
0046 alembic revision -m "descripcion_del_cambio"
0047 ```
0048
0049 ## Convención de nombres
0050
0051 Los archivos de migración siguen el patrón: `<revision_id>_<descripcion>.py`
0052
0053 Ejemplo: `add_minio_file_fields.sql` (también hay migraciones SQL directas en `backend/migrations/`).
0054
0055 ## Cuándo ejecutar
0056
0057 - Antes del primer arranque en un entorno nuevo
0058 - Después de cada deploy que incluya cambios de esquema
0059 - Los pipelines de CI/CD deben ejecutar `alembic upgrade head` como parte del proceso de deploy
