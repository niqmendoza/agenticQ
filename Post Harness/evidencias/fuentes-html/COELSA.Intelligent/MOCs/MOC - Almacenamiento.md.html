0010 # MOC — Almacenamiento
0011
0012 El almacenamiento de archivos sigue un flujo híbrido: primero local, luego migrado a [[MinIO S3]]. El acceso siempre se hace con [[URLs firmadas MinIO|URLs firmadas]].
0013
0014 ## Notas de este cluster
0015
0016 - [[Sistema híbrido de almacenamiento]] — Visión general del flujo local → MinIO y cómo coexisten los dos providers
0017 - [[Flujo de subida de archivos]] — Ciclo completo: recepción → guardado local → scheduler → MinIO
0018 - [[URLs firmadas MinIO]] — Cómo se generan presigned URLs para acceso seguro temporal
0019 - [[Scheduler de limpieza]] — Job diario que elimina archivos huérfanos y vencidos (`FILE_STORAGE_CLEANUP_DAYS`)
0020 - [[Borrado en cascada de archivos]] — Al eliminar un chat se eliminan sus archivos en MinIO automáticamente
0021 - [[Storage Dashboard]] — Endpoint `/api/v1/storage/status`; métricas de uso para administradores
0022
0023 ## MOCs vecinos
0024
0025 - [[MOC - Stack]] — MinIO S3 como componente del stack de almacenamiento
0026 - [[MOC - Arquitectura]] — Decisión de diseño del sistema híbrido y el scheduler
0027 - [[MOC - Autenticación y Permisos]] — El Storage Dashboard requiere rol `admin`
0028 - [[MOC - CI-CD y Despliegue]] — Variables de entorno S3 que deben estar en el ConfigMap de OpenShift
