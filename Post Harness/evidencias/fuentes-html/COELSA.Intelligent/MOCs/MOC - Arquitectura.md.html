0010 # MOC — Arquitectura
0011
0012 COELSA.Intelligent es un [[Fork de Open WebUI]] adaptado para infraestructura corporativa. Las decisiones de este cluster definen **qué** es el sistema y **por qué** se alejó del upstream.
0013
0014 ## Notas de este cluster
0015
0016 - [[Fork de Open WebUI]] — Qué es el fork, qué cambia y por qué no se sigue el upstream directamente
0017 - [[SPA con SSR deshabilitado]] — Por qué `ssr = false` y sus implicaciones de seguridad y compatibilidad
0018 - [[PostgreSQL como base de datos]] — Migración de SQLite a PostgreSQL para escalar en producción
0019 - [[Redis para WebSockets]] — Backend de canal que permite múltiples workers sin pérdida de eventos
0020 - [[Sistema de errores centralizado]] — Jerarquía estándar de 10 tipos de excepción con respuestas JSON consistentes
0021 - [[Headers de usuario COELSA]] — Convención de encabezados HTTP `X-COELSA.Intelligent-User-*`
0022 - [[Idioma por defecto es-AR]] — Castellano Rioplatense como único español; idiomas eliminados del fork
