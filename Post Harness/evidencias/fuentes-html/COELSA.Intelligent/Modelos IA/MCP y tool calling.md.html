0010 # MCP y tool calling
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent integra **Model Context Protocol (MCP)** para exponer herramientas (tools) a los modelos. La herramienta principal configurada es [[Cadena SearXNG Context Forge|búsqueda web via SearXNG]].
0015
0016 ## Dos modos de tool calling
0017
0018 ### 1. Native function calling
0019 Modelos que soportan function calling nativo (formato OpenAI `tools`). El backend envía las herramientas disponibles en el payload y el modelo responde con llamadas estructuradas.
0020
0021 ### 2. Non-native function calling (JSON prompt)
0022 El modelo `gpt-oss:120b` **no soporta tool calling nativo de forma confiable**. COELSA.Intelligent implementa un workaround:
0023
0024 1. Las herramientas disponibles se describen en el **system prompt** como JSON
0025 2. Se le indica al modelo que responda con un JSON específico cuando quiera llamar una herramienta
0026 3. El backend parsea la respuesta del modelo buscando el JSON de tool call
0027 4. Ejecuta la herramienta y vuelve a llamar al modelo con el resultado
0028
0029 ## Parsing robusto de JSON
0030
0031 Los modelos grandes frecuentemente incluyen texto adicional antes o después del JSON válido. El parser usa `json.JSONDecoder().raw_decode()` para tolerar este "ruido":
0032
0033 ```python
0034 # backend/server/utils/middleware.py
0035 decoder = json.JSONDecoder()
0036 obj, end_idx = decoder.raw_decode(model_response)
0037 # obj es el JSON válido; el texto después de end_idx se descarta
0038 ```
