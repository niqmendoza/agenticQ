0010 # SharePoint OneDrive integración
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent permite a los usuarios seleccionar archivos corporativos directamente desde **SharePoint** o **OneDrive** usando el **Microsoft File Picker v8**, sin necesidad de descargar y volver a subir el archivo.
0015
0016 ## Cómo funciona
0017
0018 1. El usuario hace clic en el ícono de SharePoint en el input de chat
0019 2. Se abre el File Picker en un popup/iframe usando la identidad del usuario (OAuth delegado)
0020 3. El usuario selecciona el archivo
0021 4. El backend descarga el archivo usando el token de acceso del usuario con permisos `Files.Read.All`
0022 5. El archivo se procesa como cualquier otro archivo subido (ver [[Flujo de subida de archivos]])
0023
0024 ## Requisitos de configuración
0025
0026 ### Azure AD
0027
0028 La App Registration debe tener el permiso **`Files.Read.All`** (delegado). Este permiso permite leer cualquier archivo del tenant al que el usuario tenga acceso.
0029
0030 ```env
0031 SHAREPOINT_CLIENT_ID=<azure-client-id>
0032 # Usar el mismo tenant de OAUTH_CLIENT_ID o uno separado
0033 ```
0034
0035 ### CSP
0036
0037 El Route de OpenShift debe incluir en `connect-src`:
0038 - `login.microsoftonline.com` — para el flujo OAuth del File Picker
0039 - `graph.microsoft.com` — para descargar el contenido del archivo
0040
0041 Ver `docs/OPENSHIFT-CONFIGMAP.yaml` para el ejemplo completo.
