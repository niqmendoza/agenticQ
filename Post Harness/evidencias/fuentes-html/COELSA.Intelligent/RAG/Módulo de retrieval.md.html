0010 # Módulo de retrieval
0011
0012 ## Qué es
0013
0014 El módulo de retrieval (RAG) de COELSA.Intelligent está ubicado en `backend/server/retrieval/` y orquesta el pipeline completo de indexación y búsqueda de documentos.
0015
0016 ## Estructura
0017
0018 ```
0019 backend/server/retrieval/
0020 ├── utils.py ← Utilidades de RAG: formateo de contexto, chats de referencia
0021 ├── models/ ← Modelos de embedding (sentence-transformers, etc.)
0022 ├── loaders/ ← Cargadores de documentos por tipo (PDF, DOCX, TXT, web, YouTube)
0023 ├── vector/
0024 │ ├── dbs/
0025 │ │ └── milvus_multitenancy.py ← Implementación de Milvus con multi-tenancy
0026 └── web/ ← Integración con búsqueda web (SearXNG, etc.)
0027 ```
0028
0029 ## Flujo de indexación
0030
0031 1. **Loader**: carga el documento según su tipo (PDF, web, YouTube, etc.)
0032 2. **Chunking**: divide el texto en fragmentos con overlap configurable
0033 3. **Embedding**: genera vectores con el modelo de embedding configurado
0034 4. **Inserción**: guarda vectores en [[Milvus]] con su `resource_id`
0035
0036 ## Flujo de búsqueda
0037
0038 1. **Query embedding**: genera el vector de la consulta del usuario
0039 2. **Búsqueda vectorial**: busca en la colección de Milvus con filtro por `resource_id`
0040 3. **Reranking** (opcional): ordena los chunks por relevancia
0041 4. **Contexto**: los chunks recuperados se inyectan en el prompt del modelo
0042
0043 ## Chats de referencia
0044
0045 `retrieval/utils.py` también maneja la recuperación de [[Chats de referencia|chats de referencia]] adjuntos al mensaje: busca el chat por ID y lo formatea como bloque Markdown para inyectarlo al contexto.
