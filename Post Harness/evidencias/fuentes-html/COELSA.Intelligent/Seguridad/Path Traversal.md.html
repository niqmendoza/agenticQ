0010 # Path Traversal
0011
0012 ## Qué es
0013
0014 **Path Traversal** (también llamado Directory Traversal) es una vulnerabilidad donde un atacante usa secuencias como `../../../etc/passwd` en nombres de archivo o paths para acceder a archivos fuera del directorio esperado.
0015
0016 COELSA.Intelligent aplicó sanitización de paths de entrada en **8 endpoints**.
0017
0018 ## El fix en StorageProvider
0019
0020 ```python
0021 # backend/server/storage/provider.py — LocalStorageProvider.upload_file()
0022 # Security: Path Injection Prevention
0023 # 'filename' puede contener '../../../etc/passwd'
0024
0025 # Extraer solo el nombre base (sin directorios)
0026 safe_filename = os.path.basename(filename)
0027
0028 # Resolver la ruta final y verificar que esté dentro de UPLOAD_DIR
0029 file_path = os.path.realpath(os.path.join(UPLOAD_DIR, safe_filename))
0030 if not file_path.startswith(os.path.realpath(UPLOAD_DIR)):
0031 raise ValueError("Path traversal detectado")
0032 ```
0033
0034 ## Patrón de sanitización
0035
0036 1. **`os.path.basename()`**: elimina cualquier componente de directorio del nombre
0037 2. **`os.path.realpath()`**: resuelve symlinks y `..`
0038 3. **Verificar prefijo**: confirmar que la ruta final esté dentro del directorio permitido
0039
0040 Este patrón debe aplicarse en **cualquier endpoint nuevo** que:
0041 - Acepte un nombre de archivo del usuario
0042 - Use ese nombre para operar sobre el sistema de archivos
