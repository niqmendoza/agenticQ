0010 # FastAPI y uvicorn
0011
0012 ## Qué es
0013
0014 El backend de COELSA.Intelligent está construido sobre **FastAPI 0.115** como framework HTTP, corriendo bajo **uvicorn** como servidor ASGI. Además integra **python-socketio** para la comunicación WebSocket en tiempo real.
0015
0016 ## Entry point
0017
0018 ```
0019 backend/server/main.py
0020 ```
0021
0022 `main.py` monta todos los routers, registra los middlewares y define el ciclo de vida de la aplicación (`lifespan`). La app de socketio se monta como sub-aplicación en `/ws`.
0023
0024 ## Routers registrados
0025
0026 La API expone rutas bajo `/api/v1/`:
0027
0028 ```
0029 audio, auths, channels, chats, configs, evaluations, files,
0030 files_storage_endpoints, folders, functions, groups, images,
0031 knowledge, memories, models, ollama, openai, pipelines,
0032 prompts, retrieval, storage_management, tasks, tools, users, utils
0033 ```
0034
0035 ## Middlewares
0036
0037 - `CORSMiddleware` — Orígenes permitidos configurables
0038 - `SessionMiddleware` — Sesiones HTTP
0039 - `NonceInjectionMiddleware` — Nonces CSP (ver [[CSP con nonces]])
0040 - `AuditLoggingMiddleware` — Registro de auditoría
