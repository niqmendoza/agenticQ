0010 # Ollama
0011
0012 ## Qué es
0013
0014 **Ollama** es el servidor de modelos LLM local que COELSA.Intelligent puede usar como backend de inferencia. Es la vía de acceso "nativa" a modelos que corren en la infraestructura propia.
0015
0016 ## Configuración
0017
0018 ```env
0019 OLLAMA_BASE_URL=http://localhost:11434
0020 ```
0021
0022 Puede haber múltiples URLs de Ollama en `OLLAMA_BASE_URLS` (lista JSON).
0023
0024 ## Routing de modelos
0025
0026 El sistema determina si una request va a Ollama o a [[LiteLLM proxy]] según el campo `urlIdx` del modelo. Si `urlIdx` está ausente, se usa el endpoint de Ollama nativo. Ver [[Routing de modelos IA]] y [[Validación de urlIdx]].
0027
0028 **Importante**: modelos con prefijo `ollama/` que están configurados como proxied a través de LiteLLM **deben** tener `urlIdx` para ser correctamente ruteados al endpoint OpenAI, no al nativo de Ollama. Usar el endpoint nativo de Ollama para un modelo proxied LiteLLM genera respuestas vacías.
0029
0030 ## Diferencia con LiteLLM
0031
0032 | Característica | Ollama (nativo) | LiteLLM proxy |
0033 |----------------|-----------------|---------------|
0034 | Protocolo | API Ollama nativa | OpenAI-compatible |
0035 | Modelos | Solo modelos locales Ollama | Cualquier proveedor |
0036 | Identificador | Sin `urlIdx` (o `urlIdx` = 0) | Con `urlIdx` definido |
