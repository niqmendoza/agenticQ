0010 # Redis
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent usa **Redis 7+** como backend de canal para WebSockets y como cache distribuida. Es la pieza que permite que múltiples instancias del servidor compartan el estado del socket.
0015
0016 ## Versión mínima
0017
0018 Redis **7** — para soporte de Streams y configuraciones de seguridad modernas.
0019
0020 ## Configuración
0021
0022 ```env
0023 # Redis standalone
0024 REDIS_URL=redis://localhost:6379
0025
0026 # Redis Sentinel (alta disponibilidad)
0027 REDIS_SENTINEL_HOSTS=sentinel1:26379,sentinel2:26379
0028 REDIS_SENTINEL_PORT=26379
0029 ```
0030
0031 La lógica de conexión está en `backend/server/utils/redis.py` y elige entre standalone y Sentinel según las variables definidas.
0032
0033 ## Rol en el sistema
0034
0035 - **Canal de WebSockets**: `python-socketio` usa Redis como bus de mensajes entre instancias de uvicorn. Sin Redis, los WebSockets solo funcionan con un único worker.
0036 - **Cache distribuida**: algunas operaciones costosas cachean resultados en Redis.
