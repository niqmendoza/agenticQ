## Empezar con V5

Abrí la carpeta `v5` en Copilot y completá el [prompt maestro](v5/PROMPT-MAESTRO.md) con la aplicación, el entorno y el alcance autorizado. Cada corrida publica sus notas en [v5/resultados](v5/resultados/).
