0010 # Grupos y permisos
0011
0012 ## Qué es
0013
0014 Además del sistema de [[Roles de usuario|roles]], COELSA.Intelligent implementa **grupos** con permisos granulares en formato JSON. Los grupos permiten dar acceso diferenciado a conjuntos de funcionalidades a subconjuntos de usuarios.
0015
0016 ## Modelo de datos (Group)
0017
0018 ```python
0019 class Group(Base):
0020 id: Text # UUID
0021 user_id: Text # Creador del grupo
0022 name: Text
0023 description: Text
0024 data: JSON # Datos adicionales
0025 meta: JSON # Metadatos internos
0026 permissions: JSON # Permisos del grupo
0027 user_ids: JSON # Lista de IDs de usuarios en el grupo
0028 created_at: BigInteger
0029 updated_at: BigInteger
0030 ```
0031
0032 ## Estructura del JSON de permisos
0033
0034 Los permisos se definen como un objeto JSON con capacidades específicas. Ejemplo:
0035
0036 ```json
0037 {
0038 "chat": {
0039 "file_upload": true,
0040 "web_search": false
0041 },
0042 "workspace": {
0043 "models": false,
0044 "knowledge": true
0045 }
0046 }
0047 ```
0048
0049 ## Permisos por defecto
0050
0051 La configuración de permisos iniciales para nuevos usuarios y grupos se ajustó en v1.3.0 a las necesidades corporativas de COELSA (ver CHANGELOG). Los defaults del upstream no aplicaban al contexto corporativo.
