0010 # Pipelines Azure DevOps
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent tiene **4 pipelines de Azure DevOps** que gestionan el ciclo de vida completo desde el commit hasta producción.
0015
0016 ## Los 4 pipelines
0017
0018 | Archivo | Entorno | Propósito |
0019 |---------|---------|-----------|
0020 | `azure-pipeline-DEV.yml` | DEV | Build y deploy automático de ramas de feature |
0021 | `azure-pipeline-VALIDACION.yml` | VALIDACION | Build y deploy para QA/testing |
0022 | `azure-pipeline-PROD.yml` | PRODUCCIÓN | Deploy a producción (requiere aprobación) |
0023 | `azure-pipeline-RELEASE.yml` | — | Gestión de versiones (tagging, changelogs) |
0024
0025 ## Pasos típicos de un pipeline
0026
0027 1. **Build frontend**: `npm run build:docker` (sin Pyodide — ver [[Build frontend]])
0028 2. **Build imagen Docker**: `docker build -t ...` (ver [[Dockerfile]])
0029 3. **Push a registry**: push de la imagen al registro corporativo
0030 4. **Deploy a OpenShift**: `oc apply` con la nueva imagen
0031
0032 ## Variables críticas de entorno en los pipelines
0033
0034 Las variables de entorno de la app **no** están hardcodeadas en los pipelines. Se inyectan desde:
0035 - **ConfigMap de OpenShift**: variables de aplicación — ver [[Despliegue en OpenShift]]
0036 - **Azure DevOps Variable Groups**: credenciales (secrets) del pipeline
