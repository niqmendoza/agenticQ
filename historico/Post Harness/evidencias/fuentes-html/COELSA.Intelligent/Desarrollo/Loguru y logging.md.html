0010 # Loguru y logging
0011
0012 ## Qué es
0013
0014 El backend de COELSA.Intelligent usa **loguru** como librería de logging. El nivel de log se controla por variable de entorno y se puede ajustar por módulo.
0015
0016 ## Configuración
0017
0018 ```env
0019 LOG_LEVEL=INFO
0020 ```
0021
0022 Niveles disponibles: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`.
0023
0024 ## Uso en módulos
0025
0026 ```python
0027 from server.env import SRC_LOG_LEVELS
0028 import logging
0029
0030 log = logging.getLogger(__name__)
0031 log.setLevel(SRC_LOG_LEVELS["MAIN"]) # o "MODELS", "OAUTH", etc.
0032
0033 log.info("Mensaje informativo")
0034 log.error(f"Error: {e}")
0035 log.exception(f"Error con traceback: {e}")
0036 ```
0037
0038 ## Niveles por módulo (`SRC_LOG_LEVELS`)
0039
0040 La variable `SRC_LOG_LEVELS` en `server/env.py` mapea áreas del sistema a sus niveles:
0041
0042 | Clave | Módulos afectados |
0043 |-------|------------------|
0044 | `MAIN` | Arranque, config, main.py |
0045 | `MODELS` | ORM, modelos SQLAlchemy |
0046 | `OAUTH` | Autenticación, JWT |
0047 | `RAG` | Retrieval, embeddings |
0048 | `DB` | Consultas a base de datos |
0049
0050 ## Filtrado de endpoints frecuentes
0051
0052 El log de acceso de uvicorn filtra las requests a `/health` para evitar spam en los logs:
0053
0054 ```python
0055 class EndpointFilter(logging.Filter):
0056 def filter(self, record):
0057 return record.getMessage().find("/health") == -1
0058 ```
