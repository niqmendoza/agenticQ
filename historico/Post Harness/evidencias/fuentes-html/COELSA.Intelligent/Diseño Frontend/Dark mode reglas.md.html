0010 # Dark mode reglas
0011
0012 ## Qué es
0013
0014 El dark mode de COELSA.Intelligent **invierte los roles semánticos**, no los colores primitivos. La escala Teal sigue siendo Teal; solo cambia qué tono de la escala se asigna a cada rol.
0015
0016 ## La regla fundamental
0017
0018 ```
0019 Light mode: primary = teal-40 (#006972, oscuro)
0020 Dark mode: primary = teal-80 (#57D8E6, claro)
0021 ```
0022
0023 Los primitivos no cambian; cambia qué primitivo se asigna a qué rol.
0024
0025 ## Anti-patrones de dark mode
0026
0027 | Anti-patrón | Por qué está mal |
0028 |------------|-----------------|
0029 | Usar escala directa (`bg-teal-40`) | No se invierte en dark mode |
0030 | Asumir que `text-on-primary` es siempre blanco | En dark mode `on-primary` = teal-20 (oscuro) |
0031 | Hardcodear `text-white` sobre `bg-primary` | Rompe en light mode si se ajustan los roles |
0032 | Usar `opacity-50` para el texto secundario | Debe usarse `text-on-surface/75` (opacity utility) |
0033
0034 ## Implementación técnica
0035
0036 Las CSS custom properties se definen en `src/lib/styles/colors.css` con dos bloques:
0037
0038 ```css
0039 /* Light mode (por defecto) */
0040 :root {
0041 --color-primary: #006972;
0042 --color-on-primary: #FFFFFF;
0043 /* ... */
0044 }
0045
0046 /* Dark mode */
0047 [data-theme="dark"], .dark {
0048 --color-primary: #57D8E6;
0049 --color-on-primary: #00363B;
0050 /* ... */
0051 }
0052 ```
0053
0054 Tailwind usa estas variables via `tailwind.config.js`.
0055
0056 ## Surface containers en dark mode
0057
0058 Los [[Surface Containers]] más oscuros en light mode son los más claros en dark mode. La jerarquía se mantiene: `highest` siempre es el más destacado, solo cambia si eso significa "más claro" o "más oscuro".
