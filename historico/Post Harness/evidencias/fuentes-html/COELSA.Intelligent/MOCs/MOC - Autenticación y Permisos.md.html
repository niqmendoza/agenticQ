0010 # MOC — Autenticación y Permisos
0011
0012 Todo acceso al sistema pasa por [[Azure AD login exclusivo]]. Los [[Roles de usuario]] y [[Grupos y permisos]] determinan qué puede hacer cada usuario dentro de la aplicación.
0013
0014 ## Notas de este cluster
0015
0016 - [[Azure AD login exclusivo]] — Solo OAuth Azure AD; registro local y formulario de usuario deshabilitados
0017 - [[Roles de usuario]] — Los tres roles: `admin`, `user`, `pending`; qué puede hacer cada uno
0018 - [[Grupos y permisos]] — Modelo de grupos con JSON de permisos granulares; acceso por grupo o usuario
0019 - [[JWT y sesiones]] — Generación y validación de tokens HS256; `WEBUI_SECRET_KEY`
0020 - [[bcrypt para contraseñas]] — Por qué se migró de passlib a bcrypt nativo; problema de truncación UTF-8
0021 - [[Control de acceso a recursos]] — Campo `access_control` en Knowledge y Files; modos public/private/custom
0022
