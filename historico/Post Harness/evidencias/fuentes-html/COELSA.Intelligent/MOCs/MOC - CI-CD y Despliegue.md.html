0010 # MOC — CI-CD y Despliegue
0011
0012 El ciclo de vida de versiones pasa por 4 pipelines de Azure DevOps (DEV → VALIDACION → PROD → RELEASE). El runtime es [[OpenShift]] con imágenes construidas en Docker.
0013
0014 ## Notas de este cluster
0015
0016 - [[Pipelines Azure DevOps]] — Los 4 pipelines y sus responsabilidades: DEV, VALIDACION, PROD, RELEASE
0017 - [[Dockerfile]] — CPU-only PyTorch; sin Pyodide; workarounds de SSL corporativo
0018 - [[Build frontend]] — Diferencia entre `npm run build` (con Pyodide) y `npm run build:docker` (sin Pyodide, para CI)
0019 - [[SSL corporativo en build]] — Por qué `NODE_TLS_REJECT_UNAUTHORIZED=0` está en el Dockerfile y qué riesgo implica
0020 - [[Despliegue en OpenShift]] — ConfigMap, Routes, timeout de HAProxy, creación del bucket MinIO
