0010 # MOC — Stack
0011
0012 El stack de COELSA.Intelligent cubre todas las capas: frontend, backend, persistencia, mensajería, almacenamiento de objetos, búsqueda vectorial, identidad y despliegue.
0013
0014 ## Notas de este cluster
0015
0016 ### Frontend
0017 - [[SvelteKit 2]] — Framework SPA con TailwindCSS; SSR deshabilitado; más de 4.500 módulos en build
0018
0019 ### Backend
0020 - [[FastAPI y uvicorn]] — Servidor HTTP ASGI con python-socketio para WebSockets
0021
0022 ### Persistencia
0023 - [[PostgreSQL]] — Base de datos relacional con SQLAlchemy + Alembic; versión mínima 14
0024 - [[Redis]] — Canal de WebSockets y cache distribuida; versión mínima 7
0025
0026 ### Almacenamiento de objetos
0027 - [[MinIO S3]] — Almacenamiento compatible S3 para archivos del sistema
0028
0029 ### Búsqueda vectorial
0030 - [[Milvus]] — Base de datos vectorial para RAG con multi-tenancy; versión mínima 2.4
0031
0032 ### Identidad
0033 - [[Azure AD OAuth]] — Proveedor OAuth 2.0 / OpenID Connect corporativo; único medio de login
0034
0035 ### Modelos IA
0036 - [[Ollama]] — Servidor local de modelos LLM (acceso nativo)
0037 - [[LiteLLM proxy]] — Proxy OpenAI-compatible que unifica múltiples proveedores de modelos
0038
0039 ### Despliegue
0040 - [[OpenShift]] — Plataforma de orquestación de contenedores con Azure DevOps CI/CD
