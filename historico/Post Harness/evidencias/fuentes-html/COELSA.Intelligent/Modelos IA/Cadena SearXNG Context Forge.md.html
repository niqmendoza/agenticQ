0010 # Cadena SearXNG Context Forge
0011
0012 ## Qué es
0013
0014 La integración de búsqueda web en COELSA.Intelligent usa una cadena de 4 componentes:
0015
0016 ```
0017 Open WebUI → MCPO (puerto 8000) → Context Forge (puerto 4444) → searxng-mcp → SearXNG
0018 ```
0019
0020 ## Componentes
0021
0022 | Componente | Puerto | Rol |
0023 |-----------|--------|-----|
0024 | **MCPO** | 8000 | Proxy MCP → HTTP que convierte el protocolo MCP a una API HTTP/OpenAPI |
0025 | **Context Forge** | 4444 | Orquestador de contexto; registra herramientas MCP y las expone via OpenAPI |
0026 | **searxng-mcp** | — | Servidor MCP que envuelve SearXNG con el protocolo MCP |
0027 | **SearXNG** | — | Motor de búsqueda metasearch (privado, self-hosted) |
0028
0029 ## Por qué esta cadena
0030
0031 - SearXNG es self-hosted para mantener privacidad (sin tracking de búsquedas)
0032 - MCP es el protocolo estándar para tool calling en agentes IA
0033 - MCPO convierte MCP a HTTP/OpenAPI, que es lo que Open WebUI entiende como tool server
0034
0035 ## Configuración
0036
0037 ```env
0038 TOOL_SERVER_CONNECTIONS=[
0039 {
0040 "url": "http://host:8000/contextforge",
0041 "path": "openapi.json",
0042 "auth_type": "bearer",
0043 "key": "tu-api-key"
0044 }
0045 ]
0046 ```
