0009
0010 # Chats de referencia
0011
0012 ## Qué es
0013
0014 Los **chats de referencia** permiten a los usuarios adjuntar conversaciones previas como contexto extendido al enviar un nuevo mensaje. El chat adjunto se recupera, se formatea y se inyecta en el prompt del modelo junto con el mensaje actual.
0015
0016 ## Cómo se adjunta en el cliente
0017
0018 El chat referenciado viaja como un elemento de tipo `"chat"` dentro del array `files` del payload del socket:
0019
0020 ```json
0021 {
0022 "files": [
0023 {
0024 "type": "chat",
0025 "id": "chat-uuid-del-chat-referenciado"
0026 }
0027 ],
0028 "content": "Basándote en la conversación adjunta..."
0029 }
0030 ```
0031
0032 ## Procesamiento en el backend
0033
0034 En `backend/server/retrieval/utils.py`:
0035 1. Se detecta el elemento `type == "chat"` en `files`
0036 2. Se recupera el chat por ID desde la BD (tabla `chat`)
0037 3. El historial del chat se formatea como bloque Markdown:
0038 ```
0039 ## Conversación de referencia
0040 **Usuario**: ...
0041 **Asistente**: ...
0042 ```
0043 4. El bloque se inyecta al contexto del prompt antes del mensaje del usuario
0044
0045 ## Visibilidad en la UI
0046
0047 La opción de adjuntar chats de referencia aparece en el `InputMenu` y depende del permiso `chat.file_upload` (no del historial local del sidebar). El componente `InputMenu/Chats.svelte` hace su propia llamada a `getChatList` al abrirse, independientemente del estado del sidebar.
