0010 # Milvus
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent usa **Milvus 2.4+** como base de datos vectorial para el sistema RAG. El esquema implementa [[Milvus multi-tenancy|multi-tenancy]] con 5 colecciones compartidas en lugar de una colección por recurso.
0015
0016 ## Versión mínima
0017
0018 Milvus **2.4** — requerido para el soporte de `resource_id` como campo escalar filtrable y mejoras de rendimiento en búsquedas con filtro booleano.
0019
0020 ## Configuración
0021
0022 ```env
0023 MILVUS_URI=http://localhost:19530
0024 ENABLE_MILVUS_MULTITENANCY_MODE=true
0025 ```
0026
0027 ## Colecciones
0028
0029 Las [[Cinco colecciones Milvus]] fijas son:
0030 - `_knowledge` — Bases de conocimiento
0031 - `_files` — Archivos subidos
0032 - `_memories` — Memorias de usuarios
0033 - `_web_search` — Resultados de búsqueda web
0034 - `_hash_based` — URLs (YouTube, páginas web)
0035
0036 ## Módulo principal
0037
0038 ```
0039 backend/server/retrieval/vector/dbs/milvus_multitenancy.py
0040 ```
0041
0042 Este módulo implementa `_get_collection_and_resource_id()` que determina a qué colección pertenece un recurso basándose en convenciones de nombre (prefixes).
0043
0044 **Advertencia**: cambiar cómo el frontend genera nombres de colección sin actualizar esta función puede provocar mezcla de datos entre recursos.
