0010 # MinIO S3
0011
0012 ## Qué es
0013
0014 COELSA.Intelligent usa **MinIO** (o cualquier endpoint S3-compatible) para el almacenamiento persistente de archivos subidos por usuarios. El acceso a los archivos se hace siempre mediante [[URLs firmadas MinIO|URLs firmadas (presigned URLs)]].
0015
0016 ## Variables de entorno
0017
0018 ```env
0019 S3_ACCESS_KEY_ID=minioadmin
0020 S3_SECRET_ACCESS_KEY=minioadmin
0021 S3_BUCKET_NAME=coelsa-intelligent
0022 S3_ENDPOINT_URL=http://minio:9000
0023 FILE_STORAGE_CLEANUP_DAYS=30
0024 ```
0025
0026 ## Configuración de boto3 (timeouts)
0027
0028 La configuración de `boto3` está ajustada para entornos Windows y redes corporativas:
0029 - Connect timeout: **30 segundos**
0030 - Read timeout: **120 segundos**
0031 - Reintentos: **10** con backoff exponencial
0032 - TCP keepalive: habilitado
0033
0034 Esto resolvió el problema de timeouts en uploads desde Windows documentado en el CHANGELOG v1.3.0.
0035
0036 ## Creación del bucket
0037
0038 Para crear el bucket en un entorno nuevo:
0039
0040 ```bash
0041 python scripts/create_minio_bucket.py
0042 ```
0043
0044 El script lee la configuración desde `backend/server/config.py`, que auto-carga `.env`. Ejecutar desde la raíz del proyecto.
