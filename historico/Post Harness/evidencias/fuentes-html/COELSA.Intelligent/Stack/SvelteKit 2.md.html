0010 # SvelteKit 2
0011
0012 ## Qué es
0013
0014 El frontend de COELSA.Intelligent está construido con **SvelteKit 2** en modo SPA (Single Page Application). SSR está explícitamente deshabilitado. Ver [[SPA con SSR deshabilitado]].
0015
0016 ## Estructura de carpetas relevante
0017
0018 ```
0019 src/
0020 routes/
0021 +layout.js ← ssr = false; trailingSlash = 'ignore'
0022 +layout.svelte ← layout raíz con providers de estado
0023 (app)/ ← rutas autenticadas (chat, admin, workspace)
0024 auth/ ← login via Azure AD
0025 +error.svelte ← manejo de errores HTTP
0026 lib/
0027 components/ ← componentes Svelte reutilizables
0028 stores/ ← estado global reactivo
0029 i18n/ ← traducciones (es-AR, en-GB, pt-BR)
0030 utils/ ← helpers y funciones utilitarias
0031 apis/ ← cliente HTTP para cada dominio del backend
0032 ```
0033
0034 ## Build
0035
0036 | Comando | Uso | Diferencia |
0037 |---------|-----|------------|
0038 | `npm run dev` | Desarrollo local | Hot-reload; no compatible con nonces CSP |
0039 | `npm run build` | Local completo | Incluye descarga de Pyodide (~500MB) |
0040 | `npm run build:docker` | CI/CD / Docker | Sin Pyodide; más rápido y liviano |
0041
0042 Ver [[Build frontend]] para el detalle de las diferencias y optimizaciones de CI.
