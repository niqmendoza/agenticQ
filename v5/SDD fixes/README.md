# SDD fixes

Cada subcarpeta contiene las propuestas de una corrida. Cada Markdown corresponde a un defecto de producto confirmado y abierto. El documento reúne la evidencia, referencias, alcance sugerido, criterios de aceptación y retest para pasarle a Desarrollo o a Copilot.

La propuesta parte de los hallazgos de QA. La evidencia y el código vigente determinan qué cambio implementar.
